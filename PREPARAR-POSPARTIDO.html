Que queden guardados ESCENARIO, D.T y A.T

Estos tres se ven en la pantalla pero no se estaban guardando: a la base le faltan las casillas. Esto las crea. Se hace una sola vez y no borra nada.

Antes que nada: si Chrome te ofrece traducir la página de Supabase, dile que NO. La traducción automática danna esa pantalla y sale el error de “una extension del navegador provoco un error”.
  1. Oprime COPIAR EL TEXTO.
  2. Oprime ABRIR SUPABASE. Se abre una pagina en blanco para escribir.
  3. Si Chrome ofrece traducir, escoge No traducir.
  4. Haz clic dentro del cuadro grande y pega con Ctrl + V.
  5. Oprime RUN (arriba a la derecha) o Ctrl + Enter.
  6. Abajo deben salir cuatro renglones, todos con LISTO.
  7. Vuelve a la plataforma y oprime Ctrl + F5.

Despues de esto, los partidos que vuelvas a mandar desde Programacion —oprimiendo el balon otra vez— ya le llevan al formador el escenario, el D.T y el A.T.
